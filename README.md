# Personal Portfolio — Milestone 1

## Pages
- `index.html` — Home page
- `projects.html` — Projects/Work page
- `about.html` — About/Contact page
- `wireframe/site-plan-wireframe.png` — Site plan wireframe image

## Planned visual design
- Colors: navy blue, white, and light gray
- Fonts: Arial for body text and bold Arial for headings
- Layout: simple, organized, and easy to navigate

## How to preview
Open `index.html` in a web browser. Use the navigation links to move between all three pages.

This milestone focuses on semantic HTML structure. CSS and JavaScript can be added in later milestones.
